Comment installer votre signature
1
Cliquez sur « Copier la signature » ci-dessus - la mise en forme complète est copiée.
2
Gmail : Paramètres → Général → Signature → créer ou modifier → Ctrl+V dans la zone d'édition → Enregistrer.
3
Outlook desktop : Fichier → Options → Courrier → Signatures → Nouvelle → Ctrl+V → Enregistrer.
4
Outlook web : Paramètres (roue crantée) → Courrier → Composer et répondre → coller dans la signature.
